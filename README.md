# 🌐 Cisco Networking Fundamentals

## About This Project
This project contains my learning notes about Cisco networking devices, basic IOS commands, IP addressing, and switching concepts.

## 1. Cisco Networking Devices
- Router – Connects different networks.
- Switch – Connects devices within a LAN.
- Access Point – Provides wireless connectivity.
- Firewall – Helps protect networks from unauthorized access.

## 2. Basic Cisco IOS Commands

| Command | Purpose |
|---|---|
| `enable` | Enters privileged EXEC mode |
| `configure terminal` | Enters global configuration mode |
| `show running-config` | Displays active configuration |
| `show ip interface brief` | Displays interface IP status |
| `show interfaces` | Displays interface details |
| `show version` | Displays device information |
| `show vlan brief` | Displays VLAN information |

## 3. IP Addressing
- IPv4 – 32 bits
- IPv6 – 128 bits
- Subnet Mask – Identifies network and host portions.
- Default Gateway – Provides a path to other networks.

## 4. Switching Concepts
- VLAN – Virtual Local Area Network.
- Trunk Port – Carries traffic for multiple VLANs.
- Access Port – Connects an end device to a VLAN.
- MAC Address – Identifies a network interface.

## 5. Basic Network Troubleshooting
- Check interface status.
- Verify IP configuration.
- Test connectivity using ping.
- Check VLAN configuration.
- Verify default gateway.
